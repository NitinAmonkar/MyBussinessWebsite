# Agent guide

## Project overview

This repository contains the static marketing website for NWebTech Solutions. It is dependency-free and deployed from the repository root through GitHub Pages.

## Working agreements

- Keep the site focused on software development and technology consulting.
- Preserve the single-page structure unless a change clearly requires a new page.
- Use semantic HTML, accessible labels, keyboard-visible focus states, and responsive CSS.
- Prefer the existing dependency-free approach; do not add a framework or build step for small content or styling changes.
- Keep contact details consistent with `README.md` and verify `mailto:` links before committing.
- Test changes at desktop and mobile widths and validate the HTML before pushing.

## Key files

- `index.html` — page structure, content, and styles.
- `README.md` — project and deployment documentation.
- `robots.txt` — crawler directives.

## Deployment

The `main` branch is published by GitHub Pages. Commit focused changes and push to `origin main` after validation.
